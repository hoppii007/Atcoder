# 問題
各ゴミiは、q<sub>i</sub>で割った余りがr<sub>i</sub>になる日に捨てることができる。
Q個のクエリが与えられて、各クエリを処理する系。
```
クエリ
t d
ゴミtがd日目にでた。捨てれるのは最短でいつか？
```
<br>

# 例
## 入力例1
```
2
7 3
4 2
5
1 1
1 3
1 4
1 15
2 7
```
1番目のクエリを見ると、ゴミ1を1日目に捨てようとしている。
<br>ゴミ1は7で割った余りが3の日しか捨てられないので、最初に捨てられるのは3日である。


# 瞬殺のポイント
``` d % q[i] ``` を考えて、一致してればその日に捨てれる。<br>
``` r[i] ``` に足りなければ``` r[i] - d%q[i] ``` 日後に捨てれる。
``` r[i] ``` を超えてしまう場合は、``` r[i] - d%q[i] ```減らしたいので、一旦``` q[i] ```進めてから減らす。
