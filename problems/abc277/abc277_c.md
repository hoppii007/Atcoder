## 問題

10^9 階建てのビルに N 本のはしごがかかっている。はしご i は A_i 階と B_i 階を結び、双方向に移動できる。
はしご以外の方法で別の階へは移動できない。高橋君は 1 階にいる。はしごを何回（0 回でもよい）使って、
到達できる最も高い階を求めよ。

入力:
```
N
A_1 B_1
⋮
A_N B_N
```
出力: 答えの整数を 1 つ。

例: (1,4),(4,3),(4,10),(8,3) → 10。(5×10^8,6×10^8),(6×10^8,7×10^8),(7×10^8,8×10^8) → 1（1 階から動けない）。

**制約**

- 1 ≤ N ≤ 2 × 10^5
- 1 ≤ A_i, B_i ≤ 10^9
- A_i ≠ B_i
- 入力はすべて整数
