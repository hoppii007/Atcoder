## 問題

マス 0〜N の N+1 マスのすごろく。マス 0 から出発し、マス N を目指す。
ルーレットは 1〜M の目が等確率で出て、出た目の数だけ進む。マス N を超える場合は、超えた分だけマス N から引き返す
（例：N=4 でマス 3 にいて目が 4 なら、マス 4 から 3 戻ってマス 1）。
マス N に到達したらゴールして終了する。

ルーレットを最大 K 回まで回せるとき、ゴールできる確率を mod 998244353 で求めよ
（既約分数 y/x に対し x·z ≡ y を満たす 0 ≤ z < 998244353 を出力）。

**入力**：`N M K`　**出力**：答えを1行

**制約**

- M ≤ N ≤ 1000
- 1 ≤ M ≤ 10
- 1 ≤ K ≤ 1000
- 入力は全て整数

**入出力例**：`2 2 1` → `499122177`（=1/2）／`10 5 6` → `184124175`／`100 1 99` → `0`

**問題の核**

- dp[i][j] = マス i から残り j 回以内にゴールできる確率。ゴールは吸収状態なので **dp[N][j] = 1（全 j）** で、マス N からは遷移しない。
- i < N では dp[i][j] = (1/M) Σ_{d=1..M} dp[next(i,d)][j−1]（next は跳ね返り込み）。j が必ず 1 減るので自己参照は無く、普通の DP で解ける。答えは dp[0][K]、O(NMK)。

**会話から残すこと**

- **境界条件は状態の定義から導く**：定義文に境界の状態（ここでは i = N、j = 0）を代入して値を決める。
  「j 回以内にゴール」なら、すでにゴールにいる状態は何回残っていても 1。漸化式を書いてから初期値を決めるのではなく、定義→境界→遷移の順に書く。
- **「以内」と「ちょうど」の取り違えは吸収状態の扱いに出る**：ゴール・終了状態から遷移させてしまうと「ちょうど j 回目にそこにいる」の DP になる。
  終了状態は遷移元から外す（ループを `i < N` にする）か、前向き DP なら到達分を答えに足して以降は運ばない。
- 「ちょうど j 回目にいる確率」を各 j で足し合わせて「以内」にするには、「それ以前に一度もゴールしていない」という条件が必要で、
  `(1 − p_{j−1}) × p_j` のような独立仮定の積では作れない。
- **1歩目で場合分けする式（加重平均）の読み方**：dp[i][j] = Σ_d (1/M) × P(n_d から残り j−1 回でゴール)。
  漸化式の形は「以内」でも「ちょうど」でも同じで、違いは **行き先がゴールのときに「そこから成功する確率」へ何を入れるか** だけ。
  「以内」なら、ゴールに着いた枝はその時点で成功が確定するので 1。
  例：N=2, M=2, K=2 では ½·½ + ½·**1** = 3/4 が正解。ゴールでも振り続ける元の版は ½·½ + ½·**0** = 1/4 になる。
  確率変数で書くと dp[i][j] = P(T ≤ j)（T は初めてゴールに着く時刻）。i ≠ N では T = 1 + T' なので T ≤ j ⇔ T' ≤ j−1。
  i = N では T = 0 なので漸化式を使わず、値は 1 と決まる。
  会話後の本人の申告は「完全にわかった気はしない、演習量でカバーする」（理解は未定着）。
- 前向き版：t 回目にマス x にいて未ゴールの確率を持ち、マス N に来た分を答えに加えてそこから先は遷移しない。考え方は同じ。

**難所**

- 状態定義（j 回以下でゴールする確率）は正しかったが、境界を `dp[N][0] = 1` だけにし、ループを `i = 0..N` で回してマス N からも遷移させた。
  このため `dp[0][j]` が「ちょうど j 回目にマス N にいる確率（N を通過して戻る経路も含む）」になり、入力例 2（`10 5 6`）が合わなかった。
- 修正として、答えを `ans = dp[0][0] + Σ (1 − dp[0][i−1]) · dp[0][i]` と組み直したが、これは「それ以前に未ゴール」を正しく表さず誤り。
- 正しい修正は `dp[N][j] = 1`（全 j）とし、遷移を `i < N` に限定して `dp[0][K]` を出力すること（Claude の解説で到達）。
