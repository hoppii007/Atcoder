## 問題

高橋君は何も書かれていないたくさんのボールと、空の袋を 1 つ持っている。Q 回の操作を順に行う。操作は 3 種類:

- `1 X_i`: 整数 X_i を書いたボールを袋に入れる。
- `2 X_i`: 袋の中のすべてのボールに書かれた数に X_i を加える。
- `3`: 袋の中で書かれた数が最小のボールを 1 つ取り出し、その数を記録して捨てる。

操作 3 のたびに記録される数を、記録された順に出力する。

入力形式:
```
Q
（各操作 P_i が 1 X_i / 2 X_i / 3 のいずれか）
```

**制約**

- 1 ≤ Q ≤ 2×10^5
- 1 ≤ P_i ≤ 3
- 1 ≤ X_i ≤ 10^9
- P_i = 3 である i が 1 つ以上存在する
- P_i = 3 のとき、袋には 1 つ以上のボールが入っている
- 入力は全て整数

**考察ノート**

区間sumが難しそうと感じたが、「今までのものすべてに対しての処理」は基準点だけを変更させればよさそう。
x-r を入れた後、出す時は x+r を出すので、入れてから出るまでに増えた分が加算されて出ることになる。
大小関係については、全員実際の値が +r されただけになるので変わらない。

**難所**

- 時間を使ったポイント: 区間sum の言い換え。
- つまずき: 発想は良かったが、証明が難しかった。
