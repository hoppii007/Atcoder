## 問題

AtCoder 国には N 個の都市（都市 1〜N）があり、最初はどの 2 つの相異なる都市の間も双方向の道で
結ばれていたが、そのうち M 本の道が使えなくなった。都市 1 で始まり終わる K 日間の旅を数える。
旅とは都市の列 (A_0, A_1, …, A_K) であって、次を満たすもの:

- A_0 = A_K = 1
- 各 0 ≤ i ≤ K-1 について A_i ≠ A_{i+1} であり、A_i と A_{i+1} は使用可能な道で結ばれている

異なる旅の数を 998244353 で割った余りを出力する。

入力形式:
```
N M K
U_1 V_1
  ⋮
U_M V_M
```

**制約**

- 2 ≤ N ≤ 5000
- 0 ≤ M ≤ min(N(N-1)/2, 5000)
- 2 ≤ K ≤ 5000
- 1 ≤ U_i < V_i ≤ N
- (U_i, V_i) は全て互いに相異なる
- 入力は全て整数

### 第1回 — 2026-07-10

**考察ノート**

「禁止辺」が指定されるので、使用可能辺は N*N-M でかなり多くなる。使用可能辺を見ていくのは筋が悪そう。
全ルートを計算した後、「禁止辺」を使うルート数を引けばいい？ でも「禁止辺を1回でも通るルート」の
数え上げが難しそう（道 A を通るタイミングがいろいろあるので）。単純な余事象では詰まった。
制約から考える：N ≤ 5000、K ≤ 5000 なので dp[i][j] := 頂点 i にいて残り移動回数が j の時の場合の数、を発想。
dp[i][j] = Σ dp[near][j+1]（near は i から移動可能な頂点）だが、これを
dp[i][j] = Σ dp[a][j+1]（a≠i の全頂点）− Σ dp[a][j+1]（a は i の禁止隣接）
と書き換えると、第2項は全体で M*K 回、dp 設定は N*K 回で、O(M*K + N*K) で間に合う。

**難所**

単純な（グローバルな）余事象では数え上げできない。DP の各遷移レベルで「全体 − 自分 − 禁止隣接」の
余事象を取ることで解決した。

**レビュー(LLM)**

**① 考察ノートの評価**
理想的な粒度。「使用可能辺が多い→そちらを見るのは筋が悪い」という制約起点の方針転換、
「グローバル余事象は通るタイミングが多様で数えにくい」という却下理由、最後に N,K≤5000 から
dp の次元を逆算した流れまで、分岐と却下根拠が残っている。鍵制約（N≤5000 / K≤5000 / 禁止辺 M 本）を
正しく捉え、計算量 O((N+M)K) の根拠も自力で言語化できている。
補うとより良い点：dp の定義（残り移動 j 回で頂点 i にいる場合の数、始点 dp[start][K]=1 で逆算する向き）を
1 行明示しておくと再現性が上がる。また mod 下では「全体 − 自分 − 禁止隣接」の引き算で一時的に負になりうる
——今回は modll が正規化するので問題ないが、その一言があると完璧。

**② 弱点・思考の癖**
DP / 余事象 タグの過去記録はこれが初例のため、弱点の反復は現時点で検出不可（今後の基準点になる）。
一方 abc212_d と共通する良い癖として「制約から考えてみよう」と明示的に制約起点で状態設計へ入る流れが
機能している（d は言い換え、e は dp 次元の逆算）。強みとして記録に残す。
留意点：d で「発想は良かったが証明が難しかった」とのつまずきがあった。e の遷移の正当性
（全体 − 自分 − 禁止隣接 = 許可隣接の和）は自明なので省略で問題ないが、非自明な引き算をする型では
「なぜこの引き算で過不足なく数えられるか」を 1 行残す癖をつけると、d 系のつまずき再発を防げる。

**③ 別解・より良い方針**
本解法がほぼ想定解そのもの（O((N+M)K)）。方針転換の質・計算量ともに最適で、別筋は特になし。

**④ 実装の正しさ・計算量**
正しい。dp[0][k]=1、total を前段の ntotal で持ち回して全走査の重複を回避、mrep で j=k-1..0 を回し、
答え dp[0][0]。K=1 で 0（1 手では始点に戻れない）を返すことも確認済み。計算量 O((N+M)K) ≈ 2.5×10^7 で問題なし。
軽微な指摘：(a) modll は演算ごとに % と while 正規化が走り定数倍が重いので、TL がシビアな類題では
mod 引き算を `x -= y; if(x<0) x+=mod;` の生 long long にすると速い。(b) 変数名 `nexts` は実体が
「禁止辺の隣接リスト」なので `forbidden` 等の方が意図が明確。いずれも今回の AC には影響なし。

## 問題全体のメモ

型：経路数え上げ DP × 遷移レベルの余事象。「補集合が本体より小さい／扱いやすい」ときに
Σ(全体) − Σ(除外) で遷移を書く典型。関連ライブラリ：library/ の modll（mod 付き整数型）を使用。
