## 問題

N 頂点 M 辺の単純無向グラフ G が与えられる。1 ≤ u < v ≤ N を満たす頂点の組 (u, v) のうち、次の 2 条件をともに満たすものの個数を求めよ。

- G に頂点 u と v を結ぶ辺が存在しない。
- G に辺 (u, v) を追加したグラフが二部グラフである。

二部グラフとは、各頂点を黒か白に塗り分けて、同じ色の頂点どうしを結ぶ辺が無いようにできるグラフである。

**入力**

```
N M
u_1 v_1
⋮
u_M v_M
```

**出力**

条件を満たす組 (u, v) の個数を出力する。

**制約**

- 2 ≤ N ≤ 2 × 10^5
- 0 ≤ M ≤ min(2 × 10^5, N(N−1)/2)
- 1 ≤ u_i, v_i ≤ N
- G は単純グラフ（自己ループ・多重辺なし）
- 入力はすべて整数

**問題の核**

- 非二部の成分が 1 つでもあれば答えは 0。全成分が二部なら、成分内は「異色かつ非隣接」の対、成分間は全ての対が条件を満たす。
- 二部グラフの辺は必ず異色間なので、成分内の個数は |黒|·|白| − (成分の辺数) で直接出る。全体では N(N−1)/2 − M − Σ(C(|黒_i|,2) + C(|白_i|,2))。

**会話から残すこと**

- 再帰 DFS で bool を返して失敗を検出する関数は、**子の呼び出しの戻り値を必ず伝播させる**（`if(!dfs(...)) return false;`）。捨てると、根のループで直接見つかる矛盾（奇数閉路が根を含む場合）だけ検出され、根から外れた奇数閉路を見落とす。サンプルが通って一部だけ WA になる形で現れる。
- 反例: `4 4 / 1 2 / 2 3 / 3 4 / 4 2`（奇数閉路 2-3-4 が根 1 を含まない。正解 0、バグ版は 1）。
- 二部判定は library/ に無い（`library/Graph/` を走査して確認）。本人がライブラリ化を希望（42:52）。

**難所**

- `sub_bipartite_graph` の再帰呼び出し `sub_bipartite_graph(nexts, visit, color, nxt, color[now]);` が戻り値を捨てていた。根の直接の隣接以外で見つけた同色衝突が呼び出し元に伝わらず、非二部グラフを二部と誤判定する。
