## 問題

英小文字、`,`、`"` からなる長さ N の文字列 S が与えられる。S に含まれる `"` の個数は偶数であることが保証される。

S に含まれる `"` の個数を 2K 個とすると、各 i = 1, 2, …, K について、(2i−1) 番目の `"` から (2i) 番目の `"` までの文字を「括られた文字」と呼ぶ。

S に含まれる `,` のうち、「括られた文字」でないものを `.` に置き換えた文字列を出力せよ。

入力は `N` / `S` の2行。答えの文字列を1行で出力する。

入出力例:
- `8` / `"a,b"c,d` → `"a,b"c.d`
- `5` / `,,,,,` → `.....`
- `20` / `a,"t,"c,"o,"d,"e,"r,` → `a."t,"c."o,"d."e,"r.`

**制約**

- N は 1 以上 2×10^5 以下の整数
- S は英小文字、`,`、`"` からなる長さ N の文字列
- S に含まれる `"` の個数は偶数
