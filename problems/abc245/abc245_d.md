## 問題

N 次多項式 A(x) と M 次多項式 B(x) があり、その積 C(x) = A(x)B(x)（次数 N+M）が
与えられる。A(x) の係数 A_0..A_N と C(x) の係数 C_0..C_{N+M} から、
B(x) の係数 B_0..B_M を求めて空白区切り一行で出力する。条件を満たす B は一意に存在する。

**入力形式**

```
N M
A_0 A_1 ... A_N
C_0 C_1 ... C_{N+M}
```

**出力形式**

M+1 個の整数 B_0, B_1, ..., B_M を空白区切りで一行に出力。

**制約**

- 1 ≤ N < 100
- 1 ≤ M < 100
- |A_i| ≤ 100
- |C_i| ≤ 10^6
- A_N ≠ 0
- C_{N+M} ≠ 0
- 条件を満たす B_0, ..., B_M が一意に存在する

**考察ノート**

元の式を展開すると各次数の係数が方程式になるので、B_M から順に決めていけばよさそう。

積の展開（例：A が3次、B が2次）で、次数 5,4,3,2 の係数を書き出す:

- c5 = a3·b2
- c4 = a3·b1 + a2·b2
- c3 = a3·b0 + a2·b1 + a1·b2
- c2 = a2·b0 + a1·b1 + a0·b2

一般化すると、上位から t 段目（次数 N+M-t）は

- C_{N+M-t} = Σ_{i=0}^{t} a_{N-i}·b_{M-(t-i)}

i=0 の項 a_N·b_{M-t} を左辺に移して

- b_{M-t} = ( C_{N+M-t} − Σ_{i=1}^{t} a_{N-i}·b_{M-(t-i)} ) / a_N

最高次 C_{N+M}=a_N·b_M で b_M が一意に決まり、以降は既に求めた上位の b_{M-(t-i)}
（i≥1）を使って三角状に下の次数へ降りていける。A_N≠0 が割り算の保証。

**レビュー(LLM)**

1. **考察ノートの評価** — 良好。畳み込み C_k=Σ_{p+q=k} a_p b_q を次数ごとに書き下し、
   最高次から一意に決まる三角構造を捉えられている。「A_N≠0 が割り算の保証」まで
   言語化できていれば理想（制約 A_N≠0 が鍵）。方針決定の過程（展開→係数比較→上位から）が
   明確で、横断分析に効く良いノート。

2. **弱点・思考の癖** — 詰まり無し（つまずき分類 []）。畳み込みの定義に立ち返って係数比較で
   立式する型を自力で処理できている。この「係数比較」の考察軸は今後の類題（多項式・畳み込みの
   逆問題）で再利用が効くパターンとして押さえておきたい。

3. **別解・より良い方針** — 実装した「上位次数から解く」で最適。対称に「下位次数から」
   b_0 = C_0 / A_0 として昇順に解く方針も同値（A_0≠0 は保証されないので上位からが安全）。
   N,M<100 と小さいため FFT 等は不要、O(NM) の素直な筆算で十分。

4. **実装の正しさ・計算量** — 問題なし。
   - 漸化式 `b[m-t] = (c[n+m-t] − Σ_{i=1}^{t} a[n-i]·b[m-(t-i)]) / a[n]` を正しく実装。
   - t=0..m の昇順で b を上位次数から確定させ、参照する b[m-(t-i)]（i≥1）は必ず既算の
     上位項なので依存順序が正しい。
   - 添字ガード `n-i>=0`, `m-(t-i)>=0` は妥当（実際には b の添字は常に [1,m] に収まり
     a 側のみ n-i<0 で 0 埋めが効く）。
   - 割り算は問題が一意整数解を保証するため常に割り切れる。値は |C|≤10^6・|a|≤100 で
     long long に収まりオーバーフローなし。
   - 計算量 O(M^2)（≤ 100^2）で余裕。

## 問題全体のメモ

積 C=A·B と一方の因子から他方を復元する「多項式除算」。畳み込みの定義に戻って
最高次係数から順に一意確定させる三角構造が本質。関連手法として係数比較（次数ごとの係数等置）。
