## 問題

N 個の部署があり、i 番目の部署には A_i 人の社員が所属している（社員は複数の部署に所属しない）。
相異なる K 個の部署から 1 人ずつ選んだ K 人でプロジェクトを 1 つ作る。1 人の社員が複数のプロジェクトに参加することはできない。
作れるプロジェクトの個数の最大値を求めよ。

### 制約

- 1 ≤ K ≤ N ≤ 2 × 10^5
- 1 ≤ A_i ≤ 10^12
- 入力はすべて整数である

### 入力

```
N K
A_1 A_2 … A_N
```

### 出力

作れるプロジェクトの個数の最大値を出力する。

**問題の核**

「最大いくつ作れるか」を「P 個作れるか」の判定問題に直す（P 個作れれば P−1 個も作れるので二分探索できる）。
P 個作るとき、1 つの部署は各プロジェクトに高々 1 人なので、出せるのは min(A_i, P) 人。P 個作れる ⇔ Σ min(A_i, P) ≥ P·K。

**会話から残すこと**

- 遅延セグ木の区間和は、要素を {和, 区間長} で持つ。単位元は {0, 0}（区間長 0）。各要素は構築時に {値, 1} で入れる。`lst(n)` で単位元のまま作ると、加算が効かない。
- ライブラリにプリセットを追加した。`lazy_segment_tree.cpp` を include すると `range_{add,change}_{sum,max,min}`、`segment_tree.cpp` を include すると `point_change_{sum,max,min}` が使える。値の出し入れは ll だけ。
- `find_first_condition(l, r, cond)` は、[l, r) で cond(a[i]) が true の最小の i を返す（無ければ n）。cond(a[i]) が i について単調である必要はない。
  - 正しさに必要なのは「区間内に true の要素がある ⇒ 集約値でも true」。逆向きは不要（崩れても空振りが増えるだけ）。
  - 「a[i] > 0 の最初の i」は、和では探せない（大きな負の数が混ざると区間の和が負になる）。max を集約値にすれば両向き成り立つ。一般に「a[i] ≥ k」は max、「a[i] ≤ k」は min。
  - cond(a[i]) が i について単調なら、葉を `get(i)` で二分探索してもよい（遅延セグ木で O(log² N)、集約値の条件は不要）。
- 貪欲の検証: 大きい方から K 個を 1 人ずつ使う貪欲は正しいが、A_i ≤ 10^12 では 1 人ずつ回せない。最小値ぶんまとめて引くと別物になり、反例 N=3, K=2, A=[3,3,3]（正解 4、まとめて引くと 3）。

## 問題全体のメモ

- 「最大で何個作れるか」で、個数を固定すると判定が簡単になる → 答えで二分探索。判定は Σ min(A_i, P) ≥ P·K。
- 十分性は「P 行 × K 列の表を、部署ごとに min(A_i, P) 人ずつ列方向に連続して埋める」構成で示せる。
