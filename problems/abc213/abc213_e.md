## 問題

H×W のグリッドがあり、各マスは通れるマス `.` か壁 `#`。高橋くんは左上 (1,1) の家から
右下 (H,W) の魚屋へ行きたい。高橋くんができる操作は次の2つ:

- 上下左右に隣接する **通れるマスへ移動する**（グリッド外・壁へは行けない）。
- **任意の 2×2 の正方形領域を選び、その中の壁をすべて破壊して通れるマスに変える**（＝パンチ）。

魚屋に到達するために必要な **パンチの最小回数** を求める。

入力:
```
H W
S_{1,1} … S_{1,W}
⋮
S_{H,1} … S_{H,W}
```
各 S_{i,j} は `.` または `#`。出力は最小パンチ回数を表す整数を1行。

**制約**

- 2 ≤ H, W ≤ 500
- H, W は整数
- S_{1,1} と S_{H,W} は必ず `.`

**レビュー(LLM)**

1. **考察ノートの評価** — 過不足なし。この問題の核心である「1回のパンチ＝現在地を中心とする
   5×5 から四隅を除いた領域へコスト1で移動できる」を、図で正確に言語化できている。
   自由移動をコスト0・パンチをコスト1に落として最短経路に帰着、という**帰着の骨格**が明確。
   強いて足すなら「なぜ四隅だけ不可か」を一言残すと後で再現しやすい: 2×2 の破壊は縦横
   高々2マス幅しか橋渡しできず、チェビシェフ距離2を縦横**両方**同時に稼ぐ四隅には橋を架けられない。
   また「コスト1の行き先は `#` でも良い（パンチでそのマスごと開通するから）」という点も、
   実装で全マスに辺を張った根拠として一行あると自分の実装の正当性が言語化される。

2. **弱点・思考の癖の指摘** — つまずき無しの回。難所欄が空でも、考察が言語化されているので
   分析上は問題ない（[[abc213_d]] の初回は実装で 1 WA だったが、今回は実装バグも無し）。
   グラフ帰着・最短経路系は本人の申告どおり相性が良い型と読める（difficulty 1423 に対し felt 簡単、
   自力AC）。今後この型で「felt 簡単」が続けば得意型として確定、逆に高 difficulty で崩れる回が
   出たら、帰着は見えるが辺集合の設計（どこにコスト1を張るか）でミスる、という粒度で追うと良い。

3. **別解・より良い方針** — 方針は想定解そのもの。最短経路の求解は 01-BFS が最適
   （辺重みが 0/1 なので Dijkstra より定数倍軽い）。ダイクストラでも通るが不要。
   モデルの別表現として「パンチ1回で 5×5−四隅へ飛べる」を認めれば `#`/`.` の区別なく
   コスト1辺を張れる、という今回の実装が最もシンプル。これ以上の簡略化余地は無い。

4. **実装の正しさ・計算量** — 正しい。コスト0辺は kinbo4 の `.` マスへ、コスト1辺は
   `di,dj ∈ [-2,2]` の 5×5 から四隅4つを除いた全マス（範囲内なら `#` 含む）へ張っており、
   考察の図と厳密に一致する。`di=dj=0` の自己ループや、隣接 `.` へのコスト1辺（コスト0辺と重複）が
   混じるが、いずれも最短距離を悪化させないので無害。`bfs01` は deque の 01-BFS で、
   `bfs01s[now]`（挿入後に改善され得る最新距離）を使う遅延評価型。緩和条件
   `if(bfs01s[next] <= ncost) continue` で悪化更新を弾き、距離は単調減少なので有限回で収束、
   最終距離は正しい最短距離になる。計算量は V=H·W≤2.5×10^5、辺は各頂点約25本で E≈6×10^6、
   01-BFS O(V+E) で余裕。出力 `endl` の flush も1回。問題なし。

## 問題全体のメモ

「操作（2×2 パンチ）→ コスト1辺 / 自由移動 → コスト0辺 → 01-BFS で最短」の帰着が本体。
鍵は **1回のパンチで現在地中心 5×5−四隅へ飛べる** という同値変換で、これを認めると
壁 `#` を含めて範囲内の全マスへコスト1辺を張れる。四隅が除外されるのは 2×2 が縦横両方の
チェビシェフ距離2を同時に橋渡しできないため。辺重み 0/1 なので 01-BFS が最適。
自作ライブラリ: `bfs01`（deque による 0/1 重み最短経路）、`kinbo4`/`kinbo8`（近傍列挙）。
