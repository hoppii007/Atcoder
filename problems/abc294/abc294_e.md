## 問題

2 行 L 列のマス目があり、(i, j) は上から i 行目・左から j 列目のマスを表す。各マスには整数 x_{i,j} が書かれている。
x_{1,j} = x_{2,j} を満たす整数 j の個数を求めよ。

各行の数列は連長圧縮（隣り合う要素が異なる位置で区切り、各区間を (値, 長さ) の組で表す）された形で与えられる。
1 行目は (v_{1,1}, l_{1,1}), …, (v_{1,N_1}, l_{1,N_1})、2 行目は (v_{2,1}, l_{2,1}), …, (v_{2,N_2}, l_{2,N_2})。

**入力**

```
L N_1 N_2
v_{1,1} l_{1,1}
⋮
v_{1,N_1} l_{1,N_1}
v_{2,1} l_{2,1}
⋮
v_{2,N_2} l_{2,N_2}
```

**出力**

答えを 1 行で出力する。

**制約**

- 1 ≤ L ≤ 10^12
- 1 ≤ N_1, N_2 ≤ 10^5
- 1 ≤ v_{i,j} ≤ 10^9 (i ∈ {1,2}, 1 ≤ j ≤ N_i)
- 1 ≤ l_{i,j} ≤ L (i ∈ {1,2}, 1 ≤ j ≤ N_i)
- v_{i,j} ≠ v_{i,j+1} (i ∈ {1,2}, 1 ≤ j < N_i)
- l_{i,1} + l_{i,2} + ⋯ + l_{i,N_i} = L (i ∈ {1,2})
- 入力はすべて整数

**問題の核**

両行の区切り位置をすべて合わせると、L 列は高々 N_1+N_2 個の「両行とも値が一定の区間」に分かれる。
2 つのポインタで両行の区画を同時に進め、各区間で値が一致すれば区間長を足す。L ≤ 10^12 は計算量に効かず、ll が要ることだけに効く。

**難所**

- 区画を進める `ai++`（`bi++`）と累積位置の加算を、値が一致したときの `if` の内側に書いた。値が違う区間で前進せず無限ループ（サンプル 1 の 2 区間目で止まる）。
- 区間長を `p - (a[ai].snd + ap)` と逆向きに引いた（正しくは 区画の右端 − p）。
- 前回の区切り線 `p` を更新し忘れた。
- 無限ループの症状に対してまず終了条件の追加で対処し、原因（前進が条件付き）の修正はその 2 回後の実行の後になった。

## 問題全体のメモ

- 一般化: ランレングス圧縮された 2 列の位置ごとの比較・演算は、区切り位置の和集合で区間を作り 2 ポインタで同時に進める。長さ L ではなく区画数 N_1+N_2 で回る。
- 2 ポインタの 1 ステップは「重なり長さを求める → 処理 → 終わった側を進める」。進める処理は値の比較結果に依存させない。
