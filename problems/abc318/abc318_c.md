## 問題

高橋君は N 日間の鉄道旅行を計画している。各日について、通常料金を払うか、1 日周遊パスを 1 枚使うかを選べる。i 日目の通常料金は F_i 円である。

1 日周遊パスは **D 枚セットで P 円** で売られており、何セットでも買えるが、購入は D 枚単位でしかできない。購入したパスは好きな日に 1 枚ずつ使え、旅行終了時に余っていてもよい。

N 日間の旅行でかかる合計金額（購入したパスの代金と、パスを使わなかった日の通常料金の合計）の最小値を求めよ。

**入力**

```
N D P
F_1 F_2 … F_N
```

**出力**

合計金額の最小値を 1 行で出力する。

**制約**

- 1 ≤ N ≤ 2×10^5
- 1 ≤ D ≤ 2×10^5
- 1 ≤ P ≤ 10^9
- 1 ≤ F_i ≤ 10^9
- 入力はすべて整数

（入力例 3 は答えが 3×10^9 で、32bit 整数に収まらない）

**問題の核**

- パスを使う日は料金の高い日から選ぶのが最適 → 降順ソートして先頭から D 個ずつのまとまりにし、各まとまりで「合計 ≥ P ならパス 1 セット、未満なら通常料金」。
- まとまりの合計は単調非増加なので、まとまりごとの独立判定で「何セット買うか」の最適化と一致する。端数のまとまりも 1 セット（P 円）で賄える。

**難所**

- 1 セット（D 枚）の価格 P を「D*P 円」と読み違え、加算 `ans += d*p` と比較 `total >= d*p` の 2 か所に入れた。加算側を 05:43、比較側を 06:08 に別々に修正。
- 長さ k ごとの分割で、区切り判定 `(i+1)%k == 0` を要素の push 前に置いたため、最初のまとまりが k−1 個になった（入力例 1 で 21 を出力）。
  `i != 0 && i%k == 0` に直して解消。
