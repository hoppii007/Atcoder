## 問題

N 頂点の根付き木が与えられる（根は頂点 1、i 番目の辺は頂点 u_i と v_i を結ぶ）。
頂点 i を根とする部分木に含まれる頂点の集合を S_i とする（i ∈ S_i）。
各 i について整数の区間 [L_i, R_i]（1 ≤ L_i ≤ R_i）を、すべての組 (i, j) について次を満たすように定める。

- S_i ⊆ S_j ならば [L_i, R_i] ⊆ [L_j, R_j]
- S_i ∩ S_j = ∅ ならば [L_i, R_i] ∩ [L_j, R_j] = ∅

そのような区間の組のうち、現れる整数の最大値 max{L_1, …, L_N, R_1, …, R_N} が最小となるものを1つ出力する
（複数あればどれでもよい）。

入力: N、続いて N−1 行に u_i v_i。
出力: N 行。i 行目に L_i R_i を空白区切りで。

**制約**

- 2 ≤ N ≤ 2 × 10^5
- 1 ≤ u_i, v_i ≤ N
- 入力はすべて整数
- 与えられるグラフは木である

**問題の核**

- 葉の部分木どうしは互いに素なので、葉の区間は L 個の互いに素な非空区間になる。よって最大値 ≥ L（葉の数）。
- DFS で訪れた順に葉へ 1..L を振ると、任意の部分木に含まれる葉の番号は連続区間になる。各頂点に「部分木内の葉番号の [min, max]」を割り当てれば、包含も素も満たして最大値 L を達成する。

**会話から残すこと**

- 「区間・番号を割り当てて最大値を最小化する」構築問題は、**下界（どうしても必要な個数）を先に出し、それを達成する構成を作る**という2段で片がつく。下界を1行で言えれば、「証明していないけど出す」状態を避けられる。
- オイラーツアーの「部分木 = 連続区間」は全頂点だけでなく、**葉だけ（あるいは特定の頂点だけ）に番号を振っても成り立つ**。番号を振る対象を絞ると、値域を必要最小限に圧縮できる。
- 既存ライブラリ [library/tree/euler_tour.cpp](../../library/tree/euler_tour.cpp) は全頂点の in/out を出す。今回は葉だけの番号付けなので、DFS を自前で書いたのは妥当。
