## 問題

長さ N の、英大文字と英小文字からなる文字列 S が与えられる。S に対して Q 回の操作を順に行う。
i 番目の操作は整数 2 つと文字 1 つの組 (t_i, x_i, c_i) で表される。

- t_i = 1 のとき: S の x_i 文字目を c_i に変更する。
- t_i = 2 のとき: S に含まれるすべての大文字を小文字に変換する（x_i, c_i は使わない）。
- t_i = 3 のとき: S に含まれるすべての小文字を大文字に変換する（x_i, c_i は使わない）。

Q 回の操作がすべて終わった後の S を出力せよ。

入力:

```
N
S
Q
t_1 x_1 c_1
⋮
t_Q x_Q c_Q
```

出力: 答えを 1 行で出力する。

**制約**

- 1 ≤ N ≤ 5×10^5
- S は長さ N の英大文字・英小文字からなる文字列
- 1 ≤ Q ≤ 5×10^5
- 1 ≤ t_i ≤ 3
- t_i = 1 ならば 1 ≤ x_i ≤ N
- c_i は英大文字または英小文字
- t_i ≠ 1 ならば x_i = 0 かつ c_i = 'a'
- N, Q, t_i, x_i はすべて整数

3. **別解・より良い方針** — 時刻を持たない別解: 最後の t=2/3 のクエリ番号 L を先に求め（クエリを全部読んでから）、クエリを順に適用しつつ L 番目で全体を一度だけ変換する。全体変換の実行は 1 回だけなので O(N+Q)。時刻比較が要らず、二度読みするだけ。計算量は本解と同じ。
4. **実装の正しさ・計算量** — 問題なし。O(N+Q)。初期文字を時刻 0、全体変換なしを時刻 -1 にしているので、全体変換が一度も無い場合・初期文字に全体変換が効く場合の両方が正しく扱われる。`ll i` を `rep(i, n)` が隠すが、出力ループでは外側の i を使わないので動作に影響はない（読みやすさのためにクエリ番号は別名にしてもよい）。
