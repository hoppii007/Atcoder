## 問題

長さ N の整数からなる数列 A = (A_1, …, A_N) であって、次の条件をともに満たすものは何通りあるか。
答えは非常に大きくなることがあるので、998244353 で割った余りを求めよ。

- 1 ≤ A_i ≤ M (1 ≤ i ≤ N)
- A_1 + … + A_N ≤ K

入力は `N M K` の1行。答えを1行に出力する。

（例: `2 3 4` → `6`、`31 41 592` → `798416518`）

**制約**

- 1 ≤ N, M ≤ 50
- N ≤ K ≤ NM
- 入力はすべて整数

どちらも、累積型の定義で境界の値を「定義にそのまま当てはめて」決めていない。
tags.md の DP の備考にある「状態設計→遷移→初期値の順で言語化」に、「答えの取り出し方」も加えて、毎回ログに書くとよい。

③ **別解・より良い方針**：
- **「以下」のまま解く場合**：遷移は「ちょうど」と同じ式のままでよい（遷移が dp[i-1] の値の和なので、
  累積版でも同じ式が成り立つ）。変わるのは初期値だけで、`dp[0][j] = min(j, M)`（j ≥ 1）、答えは `dp[N-1][K]`。
  005.cpp（初期値 `dp[0][i] = i`、遷移はちょうど版）はほぼこの形だったが、`rep(i, 1, min(k, m)+1)` で j ≤ M だけを埋めたため
  j > M の `dp[0][j] = M` が 0 のまま残っていた（例1 は dp[0][j] を j ≤ 3 しか参照しないので 6 で合い、例2 で合わない）。「以下」の定義のまま初期値を定義に当てはめていれば、ここで通っていた。
- **高速化**：遷移 `Σ_{a=1..M} dp[i-1][j-a]` は dp[i-1] の区間和なので、累積和を持てば O(NK) になる
  （[累積和DP](../../tags.md)。本問では O(NKM) で十分）。

④ **実装の正しさ・計算量**：問題なし。`rep(jj, 1, min(j, m+1))` は 1 ≤ jj ≤ min(j−1, M) を回すので、
j − jj ≥ 1 が保たれる（dp[i-1][0] = 0 なので jj = j を除いても値は同じ）。i = 0 の初期化 `rep(i, 1, min(k, m)+1)` で
j > M は 0 のまま、これは「ちょうど j」の定義と合っている。N = 1 のときは遷移ループが回らず、答えは min(K, M) で正しい。
計算量 O(NKM) ≤ 50×2500×50 = 6.25×10^6、メモリ N×(K+1) 個の modll で問題なし。
- 推移で直した誤り：003〜005 の状態定義と出力の食い違い（難所を参照）。

## 問題全体のメモ

- 「ちょうど j」で数えて最後に和を取る方法と、「j 以下」の定義のまま初期値だけ `min(j, M)` に変える方法は、どちらも同じ遷移式で書ける。
  遷移が前の段の値の和（線形）なら、累積型の定義でも遷移は変わらず、初期値と答えの取り出し方だけが変わる。
