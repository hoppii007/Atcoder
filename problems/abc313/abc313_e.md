## 問題

（要約）`1`〜`9` からなる文字列 S に対し、f(S) を次で定める：空文字列 T から始め、i = 1, …, |S|−1 の順に
「S_i を、S_{i+1} が表す整数の回数だけ T の末尾に追加」したものを f(S) とする。
S の長さが 1 になるまで S を f(S) で置き換える操作を繰り返すとき、操作回数を 998244353 で割った余りを出力する。
操作が無限に続く場合は `-1` を出力する。

入力: `N` / `S`　出力: 操作回数 mod 998244353、または `-1`

例: S = 313 → 3111 → 311 → 31 → 3 で 4 回。S = 123456789 は無限に続くので -1。S = 11 は 1。

**制約**

- 2 ≤ N ≤ 10^6
- S は `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8`, `9` からなる長さ N の文字列

**問題の核**

- 1 以外の数字が2つ隣接すると、その組 (A,B) は毎回 …AB… または …AA の形で残り続ける → -1。隣接が無ければ必ず終わる。
- 毎回 末尾の1文字が消える（最後の文字は「追加する側」に一度も回らない）。よって末尾から順に「その文字が末尾に来るまでの回数」p を持ち回れる。
  文字 c が末尾に来た時点の回数を p とすると、c を消して直前の 1 が (c−1)·(p+1) 個増えるので、**p ← (p+1)·c** を i = N−1 … 1（先頭以外）について回すだけになる。

**会話から残すこと**

- 「文字列が毎回変形する操作の回数」は、まず小さいケースを手で数個回して「何が保存され、何が毎回1つ減るか」を探すと、端から1つずつ消える構造が見えることがある。
  消える順に（ここでは末尾から）回数を持ち回る漸化式にすると、文字列の長さが指数的に伸びても O(N) で済む。
- mod 付きの答えは「まず ll で組んで値を目で追い、サンプルが合ったら modll に置き換える」段取りで作った（本人の申告）。
