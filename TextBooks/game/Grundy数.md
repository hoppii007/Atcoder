# Grundy数について
- 2人でゲームして状態が循環せずに変化していき、動けなくなったら負け、みたいなやつ
- Nim和っぽいやつとか

# 定義
- ゲームの状態をNとしたとき、NのGrundy数g(N)は
  - g(N) = 0 <=> 負け盤面
  - g(N) != 0 <=> 勝ち盤面
  となる整数のこと。

# 求め方
- Nからいける盤面をN_1,N_2,...,N_aとすると、
- g(N) = mex({g(N_1),g(N_2),...,g(N_a)})
- mexは、それに含まれない最小の非負整数

# 複数の状態のGrundy数
- 独立したゲームが複数ある場合のGrundy数は、各状態のXORで求められる

# 例
- 状況
  - 石が積んであって、1つか2つずつ取っていく
  - 取れなくなった方が負け
- Grundy数の計算
  - N個の石が積んである場合、g(N)=mex({g(N-1),g(N-2)})

- 状況2
  - その石が複数本（M本）ある
  - 二本から1個ずつ石をとるのはダメ

- Grundy数の計算2
  - 全部のGrundy数のXORをとるだけ
