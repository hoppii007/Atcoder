## ストーリー

高橋くんは、色とりどりのスライムたちを率いる王様である。日が暮れてきたので、あちこちで遊んでいる仲間たちを、それぞれの色の巣へ帰すことにした。

スライムたちの得意技は、縦に重なり、下の仲間の弾力を借りて跳ぶ「宙返りジャンプ」だ。王様が指示を出すと、塔の上の一団がくるんとひっくり返って飛んでいく。巣に着くと、一番上から順に、巣と同じ色のスライムたちが帰っていく。

高橋くんも早く巣に帰って休みたい。できるだけ少ない指示で仲間全員を巣へ帰せるよう、ジャンプの手順を考えてほしい。

## 問題文

$N \times N$ マスの盤面がある。左上のマスの座標を $(0,0)$ とし、そこから下方向に $i$ マス、右方向に $j$ マス進んだ先のマスの座標を $(i,j)$ とする。各マスは **床** または **壁** である。

盤面には $0,1,\dots,K-1$ の $K$ 色のスライムがいる。スライムは床の上で縦に重なって **塔** を作ることができる。

- 異なる色のスライムも同じ塔に重なることができ、融合することはない。
- 塔の高さはスライムの数であり、**上限は 8**。
- スライムのいないマスの高さは 0。

初期状態では各マスのスライムは高々 1 匹であり、巣のあるマスにはいない。各色の巣が 1 か所ずつあり、スライムは自分と同じ色の巣へ帰ることを目指す。

次の操作「宙返りジャンプ」を **最大 $100000$ 回** 行える。できるだけ少ない操作回数で、すべてのスライムを帰巣させよ。

### 宙返りジャンプ

高さ $h>0$ の塔があるマス $(i,j)$ を選び、下に残す匹数 $k$、上下左右の方向 $d$、飛距離 $\ell$ を指定する。着地点の**操作前**の高さを $g$ として、次の条件をすべて満たさなければならない。

1. $k, \ell$ は整数であり、$0 \le k < h$、$1 \le \ell \le k+1$。
2. $(i,j)$ から $d$ 方向へ 1 マス, 2 マス, …, $\ell$ マス進んだ先が**すべて盤面内の床**である。途中の塔は飛び越えてよい。
3. $g + (h-k) \le 8$。すなわち、着地後の塔の高さが 8 以下でなければならない。**帰巣によって高さが減る場合も、帰巣前の高さで判定する。**

出発点の上側 $h-k$ 匹が一団となって跳び、**上下の順序を反転させて**着地点の塔の上に重なる。出発点に残る $k$ 匹と、着地点にもともといたスライムの順序は変わらない。

その後、**出発点と着地点の両方**で、以下の帰巣を行う。

### 帰巣

色 $i$ の巣があるマスでは、塔の一番上が色 $i$ である限り、そのスライムを盤面から取り除くことを繰り返す。これを **帰巣** と呼ぶ。異なる色が現れたら、その下のスライムは帰巣しない。巣のないマスでは何も起こらない。

帰巣したスライムは盤面に戻らない。帰巣は自動的に行われ、**操作回数には数えない**。

#### 帰巣の例

色 0 の巣に、下から $(0,0,1)$ の順にスライムが重なっているとする。$k=2$ として一番上の色 1 を 3 マス右にある、スライムのいない色 1 の巣へ跳ばすと、出発点の色 0 の 2 匹と着地点の色 1 の 1 匹が帰巣する。ただし、途中のマスはすべて床とする。

## 得点

操作回数を $T$、操作終了時に盤面に残っているスライムの数を $E$ とする。絶対スコアは

$$S = T + 100000 E$$

とする。**絶対スコアは小さければ小さいほど良い。**

各テストケースごとに

$$\mathrm{round}\left(10^9 \times \frac{\text{全参加者中の最小絶対スコア}}{\text{自身の絶対スコア}}\right)$$

の相対評価スコアが得られ、その和が提出の得点となる。

最終順位はコンテスト終了後に実施される、より多くの入力に対するシステムテストにおける得点で決定される。暫定テスト、システムテストともに、一部のテストケースで不正な出力や制限時間超過をした場合、そのテストケースの相対評価スコアは 0 点となり、そのテストケースにおいては「全参加者中の最小絶対スコア」の計算から除外される。システムテストは WA/TLE 等以外の結果を得た**一番最後の提出**に対してのみ行われる。

## 入力

入力は以下の形式で標準入力から与えられる。

```
N K
C_0
⋮
C_{N-1}
```

- $12 \le N \le 20$
- $4 \le K \le 12$
- $C_i$ は長さ $N$ の文字列であり、$j$ 文字目はマス $(i,j)$ の初期状態を表す。

| 文字 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | スライムも巣もない床 |
| `a`〜`l` | 色 0〜11 のスライムが 1 匹いる床 |
| `A`〜`L` | 色 0〜11 の巣がある床 |

- 床は少なくとも $2K$ マスあり、上下左右の隣接関係について連結である。
- 英字は大文字・小文字ともに先頭の $K$ 種類のみが使われ、**各大文字はちょうど 1 回**、**各小文字は 1 回以上**現れる。

## 出力

$t$ 回目の操作の出発点 $(i_t, j_t)$、残す匹数 $k_t$、方向 $d_t$、飛距離 $l_t$ を、1 行に 1 操作ずつ計 $T$ 行出力せよ。

```
i_0 j_0 k_0 d_0 l_0
⋮
i_{T-1} j_{T-1} k_{T-1} d_{T-1} l_{T-1}
```

$d_t$ は上・下・左・右に対応する `U`、`D`、`L`、`R` の 1 文字である。

## 入力生成方法

`seed=0` の入力は手動で作成されたものであり、暫定テスト、システムテストには含まれない。それ以外の入力は以下の方法で生成する。

### 生成パラメータ

- $N$ を $12$ 以上 $20$ 以下、$K$ を $4$ 以上 $12$ 以下の整数から、それぞれ独立に一様ランダムに生成する。
- スライムの密度 $\rho$ を区間 $[0.12, 0.65)$、壁の提案率 $\beta$ を区間 $[0, 0.40)$ から、それぞれ独立に一様ランダムに生成する。

### 地形

最初は全マスを床とする。全マスを一様ランダムな順番に並べる。並べた順に各マスについて、独立に確率 $\beta$ で壁への変更を試みる。変更後も床が少なくとも $2K$ マス残り、床が連結である場合に限って壁へ変更する。

### 巣と初期位置

床から異なる $K$ マスを一様ランダムに選び、選んだ順に色 $0,\dots,K-1$ の巣を置く。

巣のない床の数を $F$ とし、スライムの総数を $M = \max(K, \mathrm{round}(\rho F))$ とする。巣のない床から異なる $M$ マスを一様ランダムに選び、それぞれにスライムを 1 匹置く。

### 色の割り当て

整数区間 $[0, M-K]$ から、$K-1$ 個の整数をそれぞれ独立に一様ランダムに選ぶ（同じ値を複数回選んでもよい）。選んだ値を昇順に並べて $s_1,\dots,s_{K-1}$ とし、$s_0 = 0$、$s_K = M-K$ とする。各色 $i = 0,\dots,K-1$ のスライムの数を

$$b_i = s_{i+1} - s_i + 1$$

とする。各色 $i$ を $b_i$ 個ずつ用意し、全 $M$ 個の色を一様ランダムに並び替え、初期位置のスライムへ割り当てる。
