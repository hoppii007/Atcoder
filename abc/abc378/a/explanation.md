# 問題
4つの整数 A<sub>1</sub>, A<sub>2</sub>, A<sub>3</sub>, A<sub>4</sub> が入力される。<br>
この中から、以下の操作を何回繰り返せるか？<br>

- 同じ数字を2つ選んで削除す

また、1 &le; A<sub>i</sub> &le; 4 (0 &le; i &lt; 4)

<br>

# 例
## 入力例1
```
1 1 2 3
```
同じ数字を2つ選んで消す操作は

- 1を2つ選んで消す

の1回だけ。

## 入力例2
```
1 3 3 1
```
操作は

- 1を選んで2つ消す
- 3を選んで2つ消す

の2回。

<br>

# 発想
愚直にシミュレートしてもいいけど、1 &le; A<sub>i</sub> &le; 4 なので、

- 「1」に対して何回操作を行えるか
- 「2」に対して何回操作を行えるか
- 「3」に対して何回操作を行えるか
- 「4」に対して何回操作を行えるか

をそれぞれ求めればいい。
「i」に対して行える操作回数をf(i)とすると、
```
f(i) = (Aの中のiの個数)/2
```
となる。

<br>

# 瞬殺のポイント
すぐシミュレーションを書くんじゃなくて、同実装するのが楽か少し考えてみるのが良い。
とはいえAなので時間を使いすぎてもダメなので、愚直解法がすぐに実装できそうならそうする。
